# Sistema de Gestión de Stock para EPSON Bahía Blanca
Documentación técnica del Sistema de Gestión de Stock para la sucursal EPSON Bahía Blanca

# Descripción del proyecto
El presente repositorio contiene la documentación técnica del proyecto de desarrollo de un Sistema de Gestión de Stock para la sucursal EPSON de Bahía Blanca.
El sistema tiene como propósito optimizar el registro y control de las existencias, actualizar los movimientos de ingreso y egreso, detectar productos que alcancen el nivel mínimo de stock y generar alertas para facilitar su reposición.
El proyecto fue desarrollado como parte del Trabajo Práctico Integrador.

# Objetivo general
Desarrollar e implementar un sistema de gestión de stock que permita optimizar el control de existencias, garantizar la trazabilidad de los movimientos de inventario y mejorar la disponibilidad de información para la toma de decisiones.

# Funcionalidades principales
* Registro de ingresos y egresos de productos.
* Actualización de existencias.
* Consulta de stock disponible.
* Detección del nivel mínimo de stock.
* Generación de alertas de reposición.
* Registro de órdenes de compra.
* Gestión de proveedores.
